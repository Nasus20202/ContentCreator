# Series: Cosmic Top 5

**id:** `cosmic-top-5` · **format:** vertical short, 40–55 s · **cadence:** weekly (Tuesday) · **research:** sourced (`cc fact add`), primary sources only

## Promise to the viewer

> "Five real records from space, counted down — every number checked."

## What makes a good list

- A **measurable** ranking (distance, size, speed, temperature, age), so the order is a fact, not an opinion. No "most beautiful", no "scariest".
- A **#1 that surprises** — the payoff must be worth waiting for (e.g. the fastest human-made object is a solar probe, not a rocket).
- Every entry has a primary source (NASA/ESA/JPL fact sheets, mission pages, papers). If a single entry can't be sourced, change the list.

## Episode structure

| Beat    | Seconds  | Template                              | Purpose                                            |
| ------- | -------- | ------------------------------------- | -------------------------------------------------- |
| Hook    | 0–4      | `image` / `factCard` + `title`        | The question + a hint that #1 is unexpected        |
| #5 → #2 | 4–35     | `image` / `factCard` (one each, ~6 s) | One number + one real photo per entry              |
| #1      | 35–47    | `image` + chip                        | The payoff, with the comparison that makes it land |
| Compare | optional | `compare`                             | All five to scale, if the gap is the point         |
| Outro   | last 4–5 | `outro`                               | "Follow for the next five"                         |

## Writing rules (in addition to docs/quality-bar.md)

- Say the ranking criterion out loud once ("measured by distance from Earth, today").
- One number per entry; no lists inside lists.
- Count down (5 → 1). Never reveal #1 in the title or hook.

## Visual rules

- Real images of each entry; an entry without a real image gets a `factCard`, never an artist's impression presented as a photo.
- The rank number lives in the `title` kicker or a chip ("#3").

## Hashtags baseline

`#space #astronomy #science #top5` + 1–2 topic tags.
